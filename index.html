01 · Overview

Satu dashboard untuk
proses pengecekan.

Import data XLSX, tentukan tanggal dan jumlah batch, lalu jalankan pengecekan. Hasil langsung tampil dalam tabel dengan status yang mudah dibaca.

📊

Import XLSX

Upload file dengan kolom User ID, Kode Tiket, Betting, dan Koin. Sistem membaca dan memproses data secara otomatis.

⚡

Batch Processing

Proses pengecekan dibagi per batch agar tidak membebani browser. Anda bisa mengatur jumlah data per batch.

✅

Status Real-time

Setiap baris mendapat status: Proses (kuning), Cocok (hijau), atau Tidak Cocok (merah). Cek ulang hanya untuk yang merah.

A · Instalasi

Pasang Extension

Gunakan Chrome dan aktifkan Developer mode untuk memuat folder extension hasil extract.

01

Download & Extract

Download Auto_Chek_Manurung.zip, lalu extract ke sebuah folder.

02

Buka halaman Extensions

Di Chrome, buka chrome://extensions.

03

Aktifkan Developer mode

Nyalakan toggle Developer mode di pojok kanan atas.

04

Load unpacked

Klik Load unpacked, lalu pilih folder Auto Chek Manurung hasil extract.

05

Pin extension

Icon mahkota akan muncul di toolbar Chrome. Pin icon tersebut agar dashboard mudah dibuka.

B · Penggunaan

Cara Pakai Dashboard

Setelah extension aktif, ikuti alur berikut untuk memulai pengecekan.

01

Login & buka halaman transaksi

Buka dan login ke https://Agent.idrbo1.com/. Pastikan dashboard menampilkan “Admin terdeteksi” hijau. Tampilan yang digunakan harus /transaction-record.html.

Lihat →
02

Buka dashboard

Klik icon mahkota pada toolbar Chrome untuk membuka dashboard Auto Chek Manurung.

Lihat →
03

Import XLSX

Klik Import XLSX dan pilih file yang berisi kolom USER ID, KODE TIKET, BETTING, KOIN.

04

Tentukan tanggal & batch

Isi Tanggal yang ingin diperiksa, kemudian tentukan jumlah Cek ... data per batch. Default tanggal adalah kemarin.

05

Mulai pengecekan

Klik ▶ Mulai Cek. Sistem akan mencocokkan data XLSX dengan data asli secara otomatis.

Status Hasil
Kuning

Masih diproses: Menunggu / Mengecek.

Hijau

Data sesuai dengan hasil pengecekan.

Merah

Tidak sesuai atau data tidak ditemukan.

↻
Cek Ulang: Jika ada baris berstatus merah, klik Cek Ulang pada kolom Aksi untuk memproses baris tersebut saja. Tidak perlu mengulang seluruh pengecekan.
