Ekstensi Chrome untuk mencocokkan data XLSX (User ID, Kode Tiket, Betting, Koin) dengan data transaksi asli — otomatis, per batch, tanpa buka halaman satu-satu.

⬇ Download Auto_Chek_Manurung.zip v3.0.6 · .zip · ekstrak dulu sebelum instal

A

Instal Extension

  1. Download filenya lewat tombol di atas, lalu extract Auto_Chek_Manurung.zip.

  2. Buka Chrome, ketik di address bar: chrome://extensions

  3. Nyalakan toggle Developer mode (pojok kanan atas).

  4. Klik tombol Load unpacked.

  5. Pilih folder "Auto Chek Manurung" (hasil extract tadi).

  6. Icon mahkota akan muncul di toolbar Chrome — pin biar gampang diakses.

B

Cara Pakai Dashboard

  1. Buka & login dulu ke halaman bukan link agen https://Agent.idrbo1.com/, tunggu sampai status di dashboard berubah jadi hijau "Admin terdeteksi". Catatan: harus membuka tampilan /transaction-record.html.

    Lihat lampiran →

  2. Klik icon mahkota di toolbar untuk buka dashboard.

    Lihat lampiran →

  3. Klik Import XLSX, pilih file yang isinya kolom USER ID, KODE TIKET, BETTING, KOIN.

  4. Isi Tanggal (default kemarin) dan jumlah Cek ... data per batch.

  5. Klik ▶ Mulai Cek — sistem otomatis mencocokkan data XLSX dengan data asli.

  6. Baca hasil dari warna status di tabel:

    KuningMasih diproses (Menunggu / Mengecek)
    HijauSesuai
    MerahTidak sesuai / tidak ditemukan
Kalau ada baris yang merah, klik ↻ Cek Ulang di kolom Aksi untuk memproses ulang baris itu saja — tidak perlu ulang dari awal.
